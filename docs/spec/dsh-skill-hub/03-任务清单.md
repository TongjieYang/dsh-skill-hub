# 03 任务清单 — dsh-skill-hub

> 阶段 3/5 · 拆任务 · 判据：每步有产物路径 + 可返回退出码的过关命令。一步最多 3 个 skill。

## T1 纯函数层（lib/frontmatter.js、lib/scan.js、lib/classify.js）

- 产物：三个模块 + `tests/scan.test.mjs`、`tests/classify.test.mjs`
- 过关：`node --test tests/scan.test.mjs tests/classify.test.mjs` 退出码 0
- 覆盖：front-matter 引号/跨行/块标量；容器目录识别；同名去重；10 类分类与 override

## T2 数据层（lib/teams.js、lib/keygen.js、lib/store.js）

- 产物：三模块 + `tests/teams.test.mjs`、`tests/keygen.test.mjs`
- 过关：`node --test tests/teams.test.mjs tests/keygen.test.mjs` 退出码 0
- 覆盖：内置 4 团结构完整；用户团覆盖/恢复；三平台脚本含 `__SECRET__` 且无真实密钥路径

## T3 宿主半（index.js + cordis.patch.yml + package.json）

- 产物：`index.js`、`cordis.patch.yml`、`package.json`（含 `dsh.bundle.patch`）
- 过关：`node -e "import('./index.js').then(m=>{if(typeof m.apply!=='function')process.exit(1)})"` 退出码 0
- 覆盖：3 个工具 hand-written compiled 对象通过 schema 校验；路由 resource 返回 JSON

## T4 浏览器半（client.js）

- 产物：`client.js`（设置页：总览 / 分类 / 专家团 / Key）
- 过关：`node --check client.js`：不能直接跑（含 `window`），故用 `node -e "new Function(require('fs').readFileSync('client.js','utf8'))"` 退出码 0
- 覆盖：注册 `settings.section` + `settings.section.icon`；四分区切换；key 输入替换占位符

## T5 打包与安装

- 产物：`icon.svg`、`locale/zh.json`、`locale/en.json`、`docs/DETAIL.md`、`README.md`、`LICENSE`
- 过关：`plugin_manager install_bundle` 返回 `application` 无 error，且新会话 `GET /skill-hub/api/state` 返回 260+ skill
- 覆盖：设置面板出现「技能中枢」导航项并渲染四个分区

## T6 发布

- 产物：`git init` + 提交 + `git remote add origin git@github.com:TongjieYang/dsh-skill-hub.git` + push
- 过关：`git ls-remote origin | head -1` 非空
