# 01 需求 — dsh-skill-hub

> 阶段 1/5 · 说清楚 · 判据：每条需求都有「可验证的验收动作」。

## 1. 谁在用

个人开发者 / 一人公司，在本机跑 DeepSeek Harness（DSH），主库 skill 已达 270 条
（`~/.agents/skills/`）。日常要同时做带货视频、科普视频、应用开发、小红书运营。

## 2. 现状与痛点（这是要解决的问题）

| # | 痛点 | 具体表现 |
|---|---|---|
| P1 | skill 不可见 | 模型侧只有一份被截断的 `<available_skills>` 列表；用户在界面里没有任何「我到底装了哪些 skill」的总览，说不清主库有多少条、哪些是容器、哪些空目录。 |
| P2 | 无序 | 270 条平铺在一起，没有分类。要找「做视频的」得自己 grep 名字。AGENTS.md 已记录「列表越长，模型选错 skill 的概率越高」，但没有可操作的收敛手段。 |
| P3 | 组合靠记忆 | 做一条带货视频要串起 选题/脚本/分镜/配音/发布 五六个 skill，每次靠人肉回忆组合，无法复用、无法交接给 agent。 |
| P4 | key 乱放 | 第三方 key 散落在 `~/.zshrc`、`.env`、skill 正文里，`grep KEY` 就能捞到明文；agent 也常被要求「帮我配 key」，直接把明文写进文件。 |
| P5 | 入匙不可控 | 就算想用系统钥匙串，也得自己记 `security` 命令，写错了才发现在泄漏。且**入匙动作必须由人执行**，不能让 agent 代劳。 |

## 3. 需求（R1–R6）与验收动作

**R1 罗列本地 skill。**
扫描 `~/.agents/skills`（共享主库）、`~/.dsh/skills`（DSH 本端）、`~/.claude/skills`（可选），
解析 `SKILL.md` 的 `name` / `description`；同一 name 多份时按扫描根优先级去重并记录 shadowed。
- 验收：`GET /skill-hub/api/state` 返回 `skills.length >= 260`，且 `containers`（无 SKILL.md 的容器目录）被单独列出。

**R2 归纳分类。**
内置 10 类（内容与视频 / 写作与文案 / 图像与设计 / 开发与工程 / 飞书与协作 / 检索与知识 /
文档办公 / 地图与出行 / 电商与运营 / 其他），用「名前缀规则 + 描述关键词打分 + 兜底」自动分类；
用户手动改分类后写入 `~/.agents/skill-hub/config.json` 的 `overrides`，永久优先于自动结果。
- 验收：`classify()` 对 `baokuan-video`/`lark-doc`/`amap` 分别给出 `content-video`/`collab`/`map-travel`；
  写入 override 后同一 skill 返回 override 的分类。

**R3 专家团（team）。**
一个团 = 目标 + 有序角色（角色含职责、绑定 skill、交付物）+ 阶段。内置 4 个团：
带货视频团、科普视频团、应用开发团、小红书运营团。用户可改、可新增、可删除、可一键恢复内置。
agent 侧用 `skill_hub_team` 工具取到整团 SOP，按阶段逐个装载 skill。
- 验收：`skill_hub_team({team:'daohuo-video'})` 输出含角色、绑定 skill、阶段交付物；
  团文件落在 `~/.agents/skill-hub/teams/*.json`，重启后仍在。

**R4 key 不进 env / skill 正文，只进系统钥匙串。**
插件只生成脚本（macOS `security` / Windows DPAPI+PowerShell / Linux `secret-tool`），
**绝不执行**；secret 只在浏览器内存里，不落盘、不打日志、不发往 host。
- 验收：仓库 `grep -rn "security add-generic-password" .` 命中；`grep -rn "child_process\|exec(" lib index.js`
  **无命中**；`~/.agents/skill-hub/keys.json` 只含 env/service/account/platform/note，无 secret 字段。

**R5 有输入框。**
DSH 设置里新增一个「技能中枢 / Skill Hub」页：技能总览（搜索 + 分类筛选 + 统计）、
分类视图（改分类）、专家团（查看 / 编辑 / 保存）、Key 管理（填 env 名 / 服务名 / 账号 / 平台 / 密钥 →
出三段命令，带复制按钮）。
- 验收：设置面板出现该导航项，四个分区可切换，输入密钥后生成命令里含真实值、且刷新页面后该值消失。

**R6 发布到 GitHub，README 写清功能与痛点。**
- 验收：仓库有 README（痛点表 + 功能表 + 安装 + 截图位）、LICENSE、`docs/DETAIL.md`、`icon.svg`；
  `git remote -v` 指向 github.com/TongjieYang/dsh-skill-hub。

## 4. 不做（本轮范围外）

- 不做 skill 安装 / 卸载 / 市场拉取（那是 skill 管理器的事，本插件只读清单）。
- 不代用户执行任何入匙命令；不读钥匙串回显密钥。
- 不改 agent 的 system prompt（只用工具描述引导）。
